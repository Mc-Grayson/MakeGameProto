# 🎮 승부 조작단 (Match Fixers)

> *"세상의 모든 승부를 조작합니다. 합리적인 가격에."*

---

## 🎯 게임 개요

| 항목 | 내용 |
|------|------|
| 장르 | 미니게임 모음 / 리듬 액션 |
| 플랫폼 | PC (Web/Steam), 모바일 추후 고려 |
| 레퍼런스 | 리듬 천국, 메이드 인 와리오, 쿠우키 오요메 |
| 그래픽 | 허접한 도트 / 플래시 애니메이션 스타일 |
| 톤 | 코믹 + 약간의 애수 (고단한 프리랜서의 삶) |

---

## 🧑‍💼 세계관

플레이어는 **승부 조작 전문 프리랜서**. 약한 염력(念力)을 가진 초능력자지만 대단한 능력은 아니라서, 물리적으로 개입하는 건 불가능하다. 대신 **타이밍**, **집중**, **섬세한 판단**으로 승부의 흐름을 미세하게 바꾼다.

- 단가를 낮추고 물량으로 승부 → 격무에 시달림
- 큰 건은 보수가 크지만 실패 리스크가 있음
- 작은 건은 초 단위로 빠르게 해치워야 수지가 맞음

## 🎮 핵심 게임플레이

### 기본 구조
- **빨간 테두리** = 이겨야 하는 대상
- **파란 테두리** = 져야 하는 대상
- 플레이어는 장면을 보고 **적절한 타이밍에 정확한 입력**을 해서 결과를 유도함

### 입력 방식
- 단순 탭/클릭 (타이밍 게임)
- 방향 입력 (어디로 영향을 줄지)
- 홀드 & 릴리즈 (염력 집중)

### 난이도 분류

| 등급 | 예시 | 플레이 시간 | 보수 |
|------|------|------------|------|
| ⚡ 일상 (초단위) | 자리 쟁탈, 가위바위보 | 5~15초 | 소액 |
| 🎯 소형 | 보드게임, 낚시 | 30~60초 | 중간 |
| 🏆 대형 | 야구 경기, 경마 | 2~5분 | 고액 + 리스크 |

## 📋 미니게임 아이디어 목록

### ⚡ 일상 의뢰 (허접 시리즈)
- **지하철 자리 쟁탈전** - 문이 열리는 순간, 빨간 사람이 앉도록 타이밍에 맞춰 파란 사람 발 앞에 장애물(가방)이 걸리게
- **시어머니 vs 며느리 수라장** - 대화 중 특정 타이밍에 개입해서 흐름 바꾸기
- **편의점 마지막 삼각김밥** - 둘이 동시에 손 뻗을 때 빨간 사람이 먼저 잡도록
- **가위바위보** - 상대가 낼 것을 읽고 염력으로 근육에 미세하게 영향
- **엘리베이터 닫힘 버튼** - 빨간 사람이 타기 전에 파란 사람이 누르지 못하게

### 🎯 소형 의뢰
- **낚시 대회** - 물고기가 빨간 사람 낚싯대에 걸리도록 유도
- **보드게임 주사위** - 주사위 굴러가는 순간 염력으로 미세하게 회전에 영향
- **오디션 심사** - 심사위원의 펜이 특정 이름에 체크하도록 손떨림 유도
- **달리기 경주 (운동회)** - 파란 팀 신발끈 풀리게 타이밍 맞추기

### 🏆 대형 의뢰
- **야구 경기** - 타자의 스윙 타이밍, 투수의 볼 궤적에 개입 (멀티 스테이지)
- **경마** - 말들의 컨디션과 기수 집중도에 영향
- **바둑 대국** - 상대 선수가 특정 수를 두도록 유도 (시간 압박)
- **TV 퀴즈쇼** - 버저 타이밍 조작

## 🎨 비주얼 방향

- **해상도**: 320x180 또는 480x270 (픽셀 아트 기준)
- **프레임**: 8~12fps (의도적으로 뚝뚝한 느낌)
- **팔레트**: 스테이지별 제한 색상 (4~8색)
- **UI**: 카세트테이프/영수증 느낌의 의뢰서 화면
- **연출**: 성공 시 허접한 승리 연출, 실패 시 민망한 실패 연출

## 👤 캐릭터

### 주인공 (플레이어)
- 이름 미정 (약칭: 조작자)
- 다크서클 가득, 항상 피곤해 보임
- 염력 사용 시 관자놀이에 땀방울

### 조력자/서사 NPC
- **사무실 고양이** - 아무것도 안 하지만 항상 있음
- **의뢰인들** - 다양한 사연을 가진 의뢰인들 (게임 시작 전 짧은 의뢰 브리핑)

## 📅 개발 단계

1. **프로토타입** - 미니게임 2~3개, 코어 시스템 검증
2. **버티컬 슬라이스** - 스테이지 5~10개, UI 완성
3. **얼리 액세스 or 데모** - 공개 피드백 수집
4. **정식 출시** - 스토리 + 30개 이상 미니게임
